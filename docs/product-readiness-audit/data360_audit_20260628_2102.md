## 2. Findings by category

### A. RBAC / Governance guardrails
- **No drift detected** between central role constants and usage; permission-editing flows correctly call `invalidateMyPermissions()` (13/13).
- **High (verify):** recommendation "install" CTAs POST to backend ungated — `command-center/TopProblemsPanel.tsx:83`, `explore-design/ProjectContextPanel.tsx:181`. Confirm whether these provision account-wide resources → if so, gate with `useCanPerform`.
- **Medium:** `org-accounts/AccountLifecycleMenu.tsx:165–242` uses hardcoded org-role strings (Snowflake org domain — acceptable but non-standard).
- **Low (mitigated by parent gating):** PolicyAssignmentPanel, ProposedPoliciesPanel, mapping/EventTableModal.

### B. Route / endpoint coverage (convention)
- **High:** notifications service (entire module), `governance/fetch_grants.ts` (grants-matrix), `fetch_roles.ts` (templates, action-registry), `security_matrix.ts` (7 paths) — all hardcoded, absent from `api-contracts.ts`.
- **High:** `warehouses-tab.tsx:286` raw `fetch('/api/auth/session')` (should use `useSession()`).
- **Medium:** org-accounts reader-accounts POST/GET method mismatch (TODO at `hooks.ts:782`); `cortex/ml-features.ts` `/cortex/explore/databases`; chat inlines query params.
- **Low:** stale `@deprecated` 404 entries still exported from contracts.

### C. Real-time / SSE cache invalidation
- **High:** governance policy mutations (`policies.ts` RLS/masking create/delete/apply/remove; assignPolicyToRoles), `role_grants.ts` attach/detach — no invalidation. data-products publish/subscribe/refresh — no invalidation.
- **Medium:** `AccessManagementPanel.tsx:154` handleGrant doesn't refetch (handleRevoke does); catalog SmartRightBar tag/policy ops; GovernedActionButton invalidates permissions but not target data.
- **Modules with NO real-time wiring:** governance, data-products (partial), catalog, workflow, access-requests, connectors, observability/data-quality (partial), org-accounts (partial).

### D. UX completeness + dark mode
- **No fabricated `?? 0` placeholders found** (project rule followed ✓).
- **High (dark-mode bleed):** `mapping/TableDetailPanel.tsx:395`, `explore-design/EventTable.tsx` (15+ badges `bg-slate-100 text-slate-600` w/o `dark:`), ModelingTemplateModal gradient badge.
- **Medium:** missing empty-guards / skeletons in `data-quality/page.tsx`, `mapping/Step0ProjectManagement.tsx`, explore-design KPI fetch; color-only error indicators (a11y).
- Mostly mechanical; well-suited to `/review-ux --fix` per module.

### E. DWH coverage (BI / DQ / lineage / modeling)
- **explore-design (critical, backend):** ~50 not-implemented `/explore-design/*` routes block deploy/version/approval — **deferred (backend)**.
- **High:** BI charts don't link to source-table lineage or DQ metrics; DQ results can't drill through to affected BI dashboards (no bidirectional traceability).
- Verdicts: Observability/lineage **good**; BI **partial**; DQ **partial**; modeling **critical (backend-blocked)**.

### F. AI scan / detect / prevent (roadmap, 3 pillars)
- **Modeling:** schema lint exists (FK/circularity/drift) + PII classification; **missing** query-cost estimation pre-deploy, grain/cardinality validation, PII→policy auto-recommendation.
- **BI:** query analytics + redundant-query detection exist; **missing** cost-anomaly baseline/auto-disable, chart-type recommender.
- **Workflow:** ML-anomaly block + readiness checks exist; **missing** governed-data-access pre-flight ("can this role read all input tables?"), DQ-threshold execution gate, lineage cycle detection.
- **Biggest opportunity per pillar:** modeling → cost-estimate API in pre-deploy; BI → cost anomaly guard; workflow → governed-access pre-flight (core CDP/agent safety gate).

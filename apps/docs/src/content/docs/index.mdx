## Quick Overview

| Feature | Details |
|---------|---------|
| **Base URL** | `https://api.datalab360.io` |
| **Auth** | JWT Bearer token via `POST /signin` |
| **Format** | JSON (responses compressed via GZip) |
| **Errors** | 3-type contract: 500 (server), 400/404 (connection), 422 (Snowflake SQL) |
| **Rate Limits** | Auth: 20/min, AI: 20/min, Bulk ops: 10/min |
| **Caching** | Redis + Snowflake result cache, SSE invalidation |
